# AuraShield

🏆 **1st Prize Winner – Ideathon**

AuraShield is an ESP32-based wearable designed to enhance women's safety through intelligent multi-sensor monitoring. It analyzes data from multiple sensors to classify situations as **SAFE**, **ALERT**, or **DANGER**, with support for manual panic activation and emergency alerts.

## Features

- Multi-sensor emergency detection
- Real-time safety monitoring
- SAFE / ALERT / DANGER classification
- Manual panic button
- LED status indication
- ESP32-based wearable prototype

## Hardware

- ESP32
- PIR Sensor
- ECG Sensor
- GSR Sensor
- Sound Sensor
- Push Button
- LEDs

## Technologies

- Arduino IDE
- Embedded C++
- ESP32
- IoT
